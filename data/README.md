# Data & Model — Rule-Based Recommendation Engine

Deterministic, rule-based recommender for learning resources. No ML —
every score is produced by explicit, explainable rules so results are
reproducible and easy to justify in the project report.

## Files in this folder

| File | Purpose |
|---|---|
| `rule_engine.py` | `RuleEngine` class — loads resources from CSV, scores and ranks them against a query and optional user profile |
| `sample_resources.csv` | Sample dataset of learning resources across programming, mathematics, and data-science |
| `test_rule_engine.py` | Unit tests covering keyword matching, level preference, hard filters, and determinism |

## Data schema (`sample_resources.csv`)

| Column | Type | Required? | Description |
|---|---|---|---|
| `id` | string | yes | Unique resource ID |
| `title` | string | yes | Resource title |
| `topic` | string | yes | Subject area (e.g. `programming`, `mathematics`) |
| `tags` | string | yes | Semicolon-separated keywords (e.g. `python;hands-on`) |
| `level` | string | yes | Difficulty: `beginner`, `intermediate`, or `advanced` |
| `url` | string | yes | Link to the resource |
| `duration_minutes` | number | optional | Length of the resource in minutes — enables the `max_duration` filter |
| `rating` | number | optional | Average rating (e.g. out of 5) — enables the `min_rating` filter |

`duration_minutes` and `rating` are optional: if a row omits them, the
engine simply skips the rules that depend on them rather than erroring.

## Usage

```python
from rule_engine import RuleEngine

engine = RuleEngine()  # loads sample_resources.csv from this folder
results = engine.recommend(query, user_profile=None, limit=10)
```

- `query` (str, required): keyword to search for in title/topic/tags
- `user_profile` (dict, optional): preference/filter keys, all optional:
  - `level`: preferred difficulty — soft bonus if it matches
  - `max_duration`: hard filter, excludes resources longer than this (minutes)
  - `min_rating`: hard filter, excludes resources rated lower than this
- `limit` (int): max number of results to return

Returns a list of dicts, each with `id`, `title`, `score`, `url`, `reason`
(a human-readable explanation of how the score was built), sorted by
score descending.

These were generated by running the exact code in this folder, so they
reflect real, current behaviour (not hypothetical output).

### Example 1 — plain keyword search

```python
engine.recommend('python')
```

```python
[
  {'id': 'R001', 'title': 'Intro to Python Programming', 'score': 4.0,
   'url': 'https://example.com/r001',
   'reason': 'query matched title (+3); query matched tags (+1)'},
  {'id': 'R004', 'title': 'Machine Learning with Neural Networks', 'score': 1.0,
   'url': 'https://example.com/r004',
   'reason': 'query matched tags (+1)'}
]
```

### Example 2 — with a level preference (soft bonus)

```python
engine.recommend('python', user_profile={'level': 'beginner'})
```

```python
[
  {'id': 'R001', 'score': 5.0, ...},   # title+tags+level match
  {'id': 'R003', 'score': 1.0, ...},   # level match only
  {'id': 'R004', 'score': 1.0, ...},   # tags match only
  {'id': 'R005', 'score': 1.0, ...}    # level match only
]
```

### Example 3 — with hard filters and rating/duration bonuses

```python
engine.recommend(
    'hands-on',
    user_profile={'level': 'beginner', 'max_duration': 60, 'min_rating': 4.0}
)
```

```python
[
  {'id': 'R005', 'title': 'SQL for Beginners', 'score': 2.4,
   'reason': "query matched tags (+1); level 'beginner' matches preference (+1); "
             "rating 4.4 exceeds minimum 4.0 (+0.4)"},
  {'id': 'R001', 'score': 1.95, ...},
  {'id': 'R003', 'score': 1.783, ...},
  {'id': 'R007', 'score': 0.183, ...}
]
```

Note: `R002`, `R004`, `R006`, `R008` are excluded entirely here — they
either exceed the 60-minute `max_duration` filter or fall outside the
query match, not just down-ranked.
