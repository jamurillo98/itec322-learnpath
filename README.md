# ITEC322 — Rule-based Recommendation Engine (Sprint 1)

Repository scaffold for Sprint 1. This project contains a minimal rule-based
recommendation engine split into Vercel services under `backend` and `frontend`,
with shared deterministic logic under `data`.

Team areas:
- Data & Model (2 people)
- Backend & API (2 people)
- Frontend (2 people)

See docs/ for Sprint 1 scope and plan.

The root `vercel.json` routes `/api/*` to the backend service and all other
requests to the frontend service.
